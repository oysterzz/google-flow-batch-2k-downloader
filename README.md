google-flow-batch-2k-downloader#Google Flow 批量 2K 下载

> 在 Google Flow 原页面选图，右键一键排队下载 2K 图片。

![Version](https://img.shields.io/badge/version-0.2.0-2563eb) ![Edge](https://img.shields.io/badge/Edge-Manifest%20V3-0b7285) ![License](https://img.shields.io/badge/license-MIT-2ea44f)

Google Flow 的批量下载未必等同于单张图片菜单中的 **2K 高清重塑**。如果需要逐张点开下载菜单，会很费时间。这个扩展把已经选好的图片排成队列，依次使用 Flow 页面自己的 **⋮ → 下载 → 2K** 操作，并等待 Edge 报告文件下载完成后再处理下一张。

**这是一款由社区制作的非官方浏览器扩展，与 Google 没有隶属关系。** 2K 选项、可用额度、输出尺寸和画质由 Flow 决定。

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 原页面选图 | 直接使用 Flow 原生多选，查看大图并勾选 |
| 右键批量下载 | 在 Flow 图片多选菜单中加入「批量 2K 重塑下载（N 张）」 |
| 顺序处理 | 一张下载结束后才开始下一张，降低结果混淆 |
| 进度与暂停 | 小面板默认收起，可展开查看日志、在本张完成后暂停 |
| 安全停止 | 图片找不到、2K 不可用、下载中断或结果不明确时停止队列 |

### 操作流程

```text
Flow 原页面多选图片
        ↓
右键 → 批量 2K 重塑下载（核对张数）
        ↓
扩展记录选图 → 退出 Flow 多选
        ↓
逐张执行 ⋮ → 下载 → 2K
        ↓
等待 Edge 确认本张下载完成 → 下一张
```

## 安装

1. 在本仓库页面点击 **Code → Download ZIP**，解压到不会移动的目录；也可以下载 [Releases](../../releases) 中的 ZIP。
2. 打开 Edge 的 `edge://extensions/`，开启**开发人员模式**。
3. 点击**加载解压缩的扩展**，选择包含 `manifest.json` 的文件夹。
4. 打开或刷新 `https://flow.google.com/` 项目页面。

安装后不需要 Node.js、Python 或其他运行环境。更新源码后，在扩展管理页点击**重新加载**，再刷新 Flow 页面。一次只启用一个版本。

## 使用

1. 在 Flow 原页面选中需要的图片。
2. 在已选图片上右键，确认菜单中的「批量 2K 重塑下载（N 张）」显示的张数正确。
3. 点击该菜单项，等待下载队列完成。需要暂停时，展开右上角的小面板。

**数量不对时不要开始下载。** 如果没有识别到图片，先展开面板并按页面提示校准。一般情况下可以直接使用，无需校准。首次使用建议先选 1–2 张，确认下载文件符合需要。

### 校准与恢复

Flow 更新页面结构时，可能需要校准：

- **图片菜单**：点击面板中的「校准图片菜单」，再点击任意图片右上角的 **⋮**。
- **选中状态**：先在 Flow 选中图片，并保留至少一张未选图片；点击「校准原页选中状态」，再点击一张已选图片。

下载中断、超时或同时出现多个 Flow 下载时，队列会停止。先检查 Edge 下载记录和 Flow 的处理状态，再到面板「日志与恢复」中解除待核对状态。运行期间不要切换项目或手动发起其他 Flow 下载。

## 工作方式与权限

扩展仅在 `https://flow.google.com/*` 运行。它通过页面元素操作 Flow 原生菜单，不请求 Google 的未公开生成接口。扩展不读取 Cookie、账号令牌，也不上传图片或日志。

| 权限 | 用途 |
| --- | --- |
| `downloads` | 检查当前图片的浏览器下载是否完成、中断或存在歧义 |
| `storage` | 保存页面菜单校准信息和当前下载监控状态 |

代码只在本地运行，未使用远程脚本或第三方服务。浏览器下载目录保持你原有的 Edge 设置。

## 已知限制

- 只处理页面已经加载的图片。若 Flow 的虚拟列表卸载了部分选图，菜单数量可能少于实际选中数；请核对张数并分批处理。
- “已下载”表示 Edge 报告文件下载完成。扩展没有读取图片像素，也不能保证视觉质量。
- 2K 功能需要 Flow 账号本身可用；扩展不会改变账号权限、额度或重塑效果。
- 页面关闭或刷新会清空本页选图与完成进度。Flow 改版后，可能需要重新校准或更新适配代码。

## 开发与测试

扩展源码位于仓库根目录，采用 Manifest V3，未使用构建步骤。Node.js 只用于运行本地测试：

```bash
npm ci
npm run check
npm test
```

测试覆盖菜单与选图识别、右键入口、顺序处理、下载状态对应、中断、空文件和歧义停止。实际使用反馈表明 0.2 版可在 Flow 页面工作；自动化测试仍使用模拟 DOM，Flow 页面更新后应先做单图回归。
